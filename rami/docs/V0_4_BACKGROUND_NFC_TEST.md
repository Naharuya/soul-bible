# RAMI v0.4 Android NFC App Launch Test

## A. 기준 태그 보존
기존 `RAMI:ELEPHANT:001` Text 태그는 v0.3 검증용으로 가능하면 그대로 보존합니다.

## B. v0.4 태그 만들기
두 번째 NFC 태그를 NFC Tools에서 URL/URI 레코드로 작성합니다.

`rami://t/E001`

## C. 테스트 1 — 앱 실행 상태
RAMI → 아이 모드 → 태그. 코끼리 콘텐츠가 열리는지 확인합니다.

## D. 테스트 2 — 앱 백그라운드
홈 버튼으로 RAMI를 뒤로 보낸 뒤 태그합니다.
성공: RAMI가 전면으로 오고 코끼리가 열립니다.

## E. 테스트 3 — 앱 종료 상태
최근 앱 화면에서 RAMI를 제거한 뒤 태그합니다.
성공: RAMI가 새로 실행되고 코끼리가 열립니다.

## 이번 버전에서 합격으로 보지 않는 조건
- 화면 완전 OFF 상태
- 잠금 화면을 우회하는 실행
- iPhone의 Android와 동일한 자동 실행

위 조건은 OS 정책 의존성이 커서 별도 단계로 검증합니다.
