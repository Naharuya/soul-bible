# RAMI v0.2 — 5 minute child test script

## Setup

- One phone with RAMI open in Child Mode.
- One physical NFC card/tag with a large elephant picture attached to it.
- Keep the adult's explanation minimal.

## Test

1. Put the elephant card where the child can see it.
2. Let RAMI show the waiting screen.
3. Say only: “어떤 카드 해볼까?” if the child needs a prompt.
4. Observe whether the child brings the elephant card to the phone.
5. After the elephant appears, observe which of the two choices the child touches.
6. If microphone is chosen, allow the child to make any sound; do not correct it.
7. Let the child replay their voice.
8. Return to the card waiting screen.
9. Wait and observe whether the child wants to tag the card again.
10. On the second tag, observe reaction to the “내 소리” choice.

## Record only observations

- Needed adult help? yes/no
- Tagged voluntarily? yes/no
- Which choice first?
- Recorded a sound? yes/no
- Replayed own sound? yes/no
- Re-tagged voluntarily? yes/no
- Smiled/laughed/spoke/repeated action? short note

Do not label these observations as developmental diagnosis or scores.
