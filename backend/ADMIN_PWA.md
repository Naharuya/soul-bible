# onaria 관리자 웹앱

주소: https://lightshare8.mycafe24.com/admin/

- 웹: 주소를 열고 관리자 인증키로 로그인합니다.
- Android: Chrome에서 열고 ‘앱 설치’를 누르거나 메뉴 → ‘홈 화면에 추가’ → ‘설치’를 선택합니다.
- PC: Chrome 또는 Edge에서 열고 ‘앱 설치’ 또는 주소창의 설치 아이콘을 선택합니다.
- iPhone/iPad: Safari 공유 메뉴 → ‘홈 화면에 추가’를 선택합니다.
- 앱 안의 브라우저에서는 외부 Chrome/Safari로 연 뒤 설치합니다.

별도 스토어 등록이나 APK 다운로드 없이 설치하는 PWA입니다.
HTTPS 연결이 필요하며, 설치 확인은 사용자가 기기에서 진행합니다.
회원 및 운영 데이터는 온라인에서만 조회합니다. 오프라인 캐시에는 공개 화면 파일만
보관하고 인증 API 응답은 저장하지 않습니다. 인증키는 현재 창의 세션에 보관하며
로그아웃 시 제거합니다.

배포 시 `backend/public` 전체(아이콘, 매니페스트, 서비스 워커 포함)를 업로드합니다.
`script/setup-admin-https.sh`는 기존 Apache 서버의 인증서와 자동 갱신을 설정합니다.
셸 파일 변경 시 서비스 워커의 `CACHE` 버전도 올려 이전 오프라인 파일을 정리합니다.
기존 앱 창은 닫았다가 다시 열면 새 서비스 워커가 적용됩니다.
