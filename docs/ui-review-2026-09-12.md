# ONARIA 흐름 개선

- `벅참`과 `벅찬`을 같은 감정으로 해석하고 기존 데이터 표기를 정리했다. 알 수 없는 감정은 행복으로 해석하지 않는다.
- 마음 카드의 개수 제한을 제거했다. 여러 저장·삭제 작업은 순서대로 처리해 서로 덮어쓰지 않는다. 이미 과거에 삭제된 기록을 복구하는 기능은 아니다.
- 입력이나 대화가 있는 상태의 뒤로가기는 종료 확인을 거친다. 사용자가 선택하면 **입력 중인 문장만** 이 기기에 임시 저장하며, 홈에서 이어 쓰거나 삭제할 수 있다. 전체 대화 복원 기능은 아니다.
- 작은 실천 선택 후 바로 카드로 이동한다. 게임은 저장 이후 성장 화면이나 홈 메뉴에서 선택한다.
- 기록 페이지를 ‘내 기록’으로 모았다. 회원가입의 선택 여부와 기기 간 동기화를 제공하지 않는다는 점을 안내하고 교회명은 선택 입력으로 바꿨다.
- 사용 횟수 저장 오류가 대화 시작을 막지 않는다.
- 최근 본 말씀 ID만 저장해 같은 감정의 후보 구절을 순환한다. 14개 본문에 로마서 15:13을 더했다. 추가 구절의 한국어 본문은 [대한성서공회 개역한글](https://www.bskorea.or.kr/bible/korbibReadpage.php?back=yes&book=rom&chap=15&sec=13&version=HAN)과 대조했다. 영어 번역을 임의로 추가하지 않았다.
- 관리자 화면은 최근 실제 응답 경로와 대체 응답 사유를 표시한다. 재시작·키 변경 후에는 미확인 상태로 돌아가며 HTTP 200과 AI 연결 성공을 구분한다. 관리자 API는 인증된 요청에만 이 정보를 제공한다.

## 검증 및 배포 범위

Flutter 전체 테스트와 analyzer, Android debug/release 빌드를 검증한다. RAMI 파일은 변경하지 않는다. iOS 빌드는 Windows에서 실행할 수 없으므로 macOS CI 검증이 필요하다.

회원가입 선택 항목과 관리자 상태 표시는 backend 배포가 필요하다. 로컬 파일 변경만으로 운영 서버에 반영되지는 않는다. 기존 운영 `.env`와 암호화된 관리자 설정을 보존해야 한다.
