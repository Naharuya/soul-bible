# onaria 0.4.1 점검 결과

현재 코드, 자동 테스트, Android 릴리즈 패키지를 점검했다. 이후 USB로 다시 연결된 SM-S908N에 0.4.1(versionCode 6)을 업데이트 설치했고, ADB 설치 `Success`, 설치 버전 조회, 앱 실행 `Status: ok`를 확인했다. 실제 기능별 조작을 모두 검증한 상태는 아니다.

| 문제 | 수정 | 확인 |

| 회원가입 설명이 기록 동기화를 지원하는 것처럼 보임 | 현재 기록은 기기 내 저장이며 자동 동기화되지 않는다고 명시 | UI 문구 확인 |

## 확인 결과

- 기존 백엔드 테스트: 338개 통과. 백엔드 코드는 변경하지 않았다.
- 수정 후 Flutter 전체 테스트: 82개 통과, API 주소 미설정 전용 테스트 1개는 기본 설정에서 제외됨.
- 후속 낭독 테스트: 4개 통과(중지, 종료, 완료, 오류).
- 빈 API 주소로 별도 실행한 대화 수명주기 테스트: 5개 통과. 위 제외 항목 포함.
- 최종 앱 및 테스트 정적 분석: `flutter analyze lib test` 문제 없음.
- 릴리즈 빌드 및 APK v2 서명 검증 통과. 버전 0.4.1, versionCode 6, Android API 24 이상.

## 해결되지 않은 항목과 다음 작업

1. **외부 서버 연결 — 최우선.** `api.onaria.ai.kr` DNS는 `104.105.128.84`로 조회되지만 HTTPS 연결이 시간 초과된다. 이 PC에 `soul-bible-server` SSH 별칭도 없다. 이 사실만으로 서버 중단, 방화벽, DNS 오류 중 원인을 단정할 수 없다. 서버 접속 정보가 확보되면 서비스 상태 → 로컬 health → 리버스 프록시/TLS → 방화벽/DNS → 외부 health 순서로 확인해야 한다. 릴리즈 앱은 기존 HTTPS 주소를 유지한다. HTTP로 보안을 낮추거나 AI가 정상인 것처럼 표시하지 않았다.
2. **실제 AI 대화·회원가입.** 외부 서버 문제로 끝까지 검증하지 못했다. 대화의 로컬 대체 흐름은 자동 테스트로 확인했지만 실제 AI 응답을 의미하지 않는다.
3. **네이버·카카오·Google 로그인.** 현재 버튼은 준비 중 안내만 표시한다. 실제 OAuth 흐름, 공급자 앱 등록/클라이언트 설정과 인증 처리가 필요하다. 회원가입은 현재 로그인 세션이나 기기 간 기록 동기화를 만들지 않는다.
4. **휴대폰 검증.** 0.4.1 업데이트 설치와 실행은 완료했다. 앱 열기 링크, 마이크 허용/거부, 한영 낭독 중지, 알림 예약/재부팅, 이미지 저장/공유의 실제 기기 조작 검증은 남아 있다.
5. **HTTPS 초대 링크.** 앱 내 필터는 수정했지만 서버 연결과 서명 인증용 assetlinks.json 배포가 확인되어야 자동 앱 열기를 검증할 수 있다. 공유용 URL 활성화는 아직 하지 않았다.
6. **성경 본문.** 앱에 포함된 문구는 UI에서 명시한 개발용 요약이다. 정식 본문으로 바꾸려면 사용할 번역본과 이용 권한이 필요하다.
