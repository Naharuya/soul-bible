# 앱 경험 개선 — 2026-09-13

로컬 기준 커밋: `d73acfed15d10c25f0241d55112f3012b62aa584`.
기존 미커밋 앱 작업 위에 요청받은 개선을 통합했다. 기존 작업을 reset/stash하거나 원격 main으로 덮어쓰지 않았다. 이 문서는 로컬 구현·검증 보고이며 운영 서버 배포나 실기기 설치 완료 보고가 아니다.

## 구현 범위

| 항목 | 동작 |
| --- | --- |
| 입력 중단·복구 | 대화 설정의 ‘입력 문장 자동 복구’를 켜면 입력 문장을 디바운스 저장하고 화면 비활성화 시 저장한다. 기본은 꺼짐이다. 홈에서 문장을 복구하며 이전 전체 대화는 복원하지 않는다. 위기 문장은 초안 저장에서 거부한다. |
| 전송 오류·취소 | 실패한 문장을 입력창에 복원한다. 재시도 또는 ‘AI 없이 다음 단계’를 직접 선택한다. 실패 자체로 턴을 소모하지 않는다. 기다리기 중지 후 늦은 응답은 무시한다. 이미 서버에 전달된 요청의 처리나 비용을 취소했다고 주장하지 않는다. |
| 음성 입력 | 기본은 인식 후 문장 확인·수정·수동 전송이다. 설정에서 자동 전송을 선택할 수 있다. 기존 입력 문장에 음성을 덧붙이고 취소하면 기존 문장을 보존한다. 화면 비활성화·종료 때 인식을 중지한다. |
| 말씀 출처 | 번역 필드, 성경 위치, 등록된 감정·주제 분류에 근거한 연결 이유를 표시한다. 데이터에 등록된 허용 HTTPS 출처만 연다. 출처 없는 항목은 링크 미등록·검토 필요를 명시한다. 경전 본문·새 번역·교리를 생성하지 않는다. |
| 말씀 낭독 | 설치된 언어별 음성 중 엔진이 제공하는 품질 정보를 사용해 선택한다. 네트워크 필수·미설치로 표시된 음성은 자동 후보에서 제외한다. 한국어 목소리 선택, 차분하게/편안하게/천천히 속도를 제공하고 설정을 기기에 저장한다. 읽기 안내와 본문 사이에 줄바꿈을 넣으며 본문 문자는 변경하지 않는다. 정지·배경 전환·다음 단계에서 낭독을 중지한다. |
| 작은 실천 | 해봤어요/아직이에요/바꿀래요를 카드에 기록한다. 원래 실천은 보존하고 바꾼 실천은 별도 필드에 저장한다. 홈은 최근 7일 중 오늘 이전의 미완료 실천을 안내한다. 완료·오늘·미래·오래된 기록은 재권유에서 제외한다. |
| 일주일 돌아보기 | 기기 카드의 감정별 횟수, 해봤다고 기록한 실천 수, 함께한 말씀과 실천 상태를 표시한다. AI 호출·누락일 추정·심리 진단은 하지 않는다. |
| 개인정보 | 기기/서버/음성/의견의 처리 범위를 구분한다. 확인 대화상자를 거쳐 초안·마음카드와 실천·저장 말씀·여정·최근 말씀 선택 기록을 각각 삭제한다. 다른 설정과 서버 회원 정보는 삭제하지 않는다. |
| 개선 의견 | 평가와 이유를 선택하고 보내기를 눌러야 전송한다. 대화·회원 정보·자유 서술은 전송하지 않는다. 실패 시 선택을 유지하고 성공 응답을 확인한 뒤에만 접수 표시를 한다. |

## 의견 API와 Admin

- `POST /v1/feedback`: 기존 앱 토큰 설정과 `/v1` 요청 제한을 적용한다. `submissionId`, `rating`, `reason`만 허용하는 strict 스키마다. 성공은 HTTP 202 `{ "accepted": true }`다.
- `GET /v1/admin/feedback`와 기존 overview의 추가 `feedback` 필드: 기존 관리자 인증 및 `no-store` 정책을 사용한다.
- Admin 이용 분석 화면에 의견 집계를 추가했다. 집계는 서버 프로세스 시작 이후이며 재시작하면 초기화된다. 영속 DB나 운영 migration을 추가하지 않았다. 즉시 재시도 중복 방지 식별자는 최대 1,000개만 보관한다.
- Admin shell cache 버전을 v7로 올렸다. `/v1` API는 서비스 워커 캐시 대상이 아니다.
- 현재 운영의 v2 패키지에는 이 API가 없다. 이 변경을 검증된 CI artifact로 별도 배포하기 전에는 앱 의견 전송이 실패 안내를 표시한다.

## 남은 운영 확인

- 연결된 Android 기기가 없어 설치·실제 목소리 청취·전화 수신·잠금·복귀·TalkBack은 미검증이다. 목소리 자연스러움과 줄바꿈의 쉼은 기기 엔진에 따라 다르다. 신경망 음성 API나 유료 TTS 호출을 추가하지 않았다.
- Windows 환경이므로 iOS simulator compile과 VoiceOver는 미실행이다.
- 회원 본인 인증과 계정 삭제 API는 기존 앱에 없다. 해당 기능을 제공한다고 표시하거나 전화번호만으로 서버 회원 삭제를 허용하지 않았다. 문의처·처리 절차는 운영자가 정식 공개 전에 확정해야 한다.
- 기존 미커밋 변경과 의존 관계가 있어 이번 작업을 임의로 섞어 commit/push하지 않았다. 원격 통합과 이번 변경 SHA의 CI 확인은 남아 있다.

음성 선택·속도 설정의 플랫폼 근거: [Android Voice](https://developer.android.com/reference/kotlin/android/speech/tts/Voice), [Android TextToSpeech](https://developer.android.com/reference/kotlin/android/speech/tts/TextToSpeech). 실제 연동은 설치된 `flutter_tts 4.2.5` 소스의 반환 형식을 확인했다.
