# ONARIA Master Project Log

Last updated: 2026-09-13

이 문서는 ONARIA(구 SoulBible/MindBible) 프로젝트의 핵심 결정, 구현 상태, 운영 원칙, 최근 변경 요청을 한 곳에 보존하기 위한 마스터 로그다. GitHub 코드/이슈/테스트 결과가 실제 구현 상태의 최종 근거이며, 이 문서는 프로젝트 연속성을 위한 요약 기록이다.

## 1. 제품 핵심

ONARIA는 사용자의 현재 감정과 마음 상태를 안전하게 살핀 뒤 심리적 성찰과 신앙/말씀을 연결하고, 작은 행동까지 이어주는 감정 기반 AI 마음대화 서비스다.

핵심 경험은 다음과 같다.

1. 서비스/체크인 안내
2. 감정 선택
3. 감정 강도
4. AI 마음대화
5. 말씀 + 작은 실천
6. 오늘의 마음카드
7. 저장/작은 성장 기록

초기 원칙은 짧은 3분 경험, 판단하지 않는 표현, 사용자의 마음을 먼저 이해한 뒤 말씀과 행동을 연결하는 것이다.

## 2. UX / 안전 원칙

- 사용자의 감정을 판단하거나 단정하지 않는다.
- 안전하고 긍정적이며 부드러운 표현을 사용한다.
- 위기/자해 위험은 일반 대화보다 우선한다.
- 위기 감지 시 한국 기준 109/112/119 등 즉시 도움 경로를 제공한다.
- 질문은 사용자가 답하기 쉽게 짧고 구체적으로 구성한다.
- 질문 아래 예시 문구는 현재 질문에 대한 직접적인 1인칭 답변이어야 한다.
- 질문에 선택지가 있으면 예시도 해당 선택지와 직접 연결한다.
- 무관한 범용 예시를 억지로 표시하지 않는다.
- 음성 입력과 말씀 낭독을 지원한다.

## 3. AI / Multi-Agent 구조

AI Router의 기본 역할:

- 감정 분류
- 위험 감지
- 간단 공감
- 일반 마음대화
- 말씀 검색/RAG
- 마음카드 템플릿
- 대화 요약/메모리
- 기도문
- 신앙 질문

에이전트 방향:

- 한국어/영어 성경
- 임상심리 성찰
- 심리·신앙 통합
- 안전한 긍정 표현
- 확장 종교: 천주교, 불교, 유대교, 이슬람, 힌두교, 유교 등

대화 종료 시 전체 원문을 계속 API에 보내는 대신 저비용 요약 메모리를 만들고 다음 대화에는 요약 + 최근 일부 + 현재 질문을 사용하는 방향을 유지한다.

## 6. 마음대화 현재 핵심 규칙

- 핵심 마음 질문은 3턴 구조를 유지한다.
- 질문 후 말씀으로 자연스럽게 전환한다.
- 질문과 하단 예시의 의미적 정합성을 반드시 유지한다.
- 예시를 탭하면 실제 답변으로 전송 가능해야 한다.
- 마음카드에는 감정, 강도, 말씀, 작은 실천, 필요한 요약/인사이트를 저장한다.

### 질문-예시 정합성 작업

GitHub Issue #2.

예: 질문이 `지금 가장 필요하다고 느끼는 것은 위로, 이해, 쉼, 용기 중 무엇에 가까운가요?`라면 다음과 같이 직접 대응한다.

- 지금은 그냥 위로받고 싶어요.
- 제 마음을 누군가 알아줬으면 좋겠어요.
- 아무 생각 없이 잠시 쉬고 싶어요.
- 다시 움직일 수 있는 용기가 필요해요.

## 8. 빛 모으기 십자가 게임

게임의 목적은 경쟁이나 점수 획득이 아니라 대화 후 잠시 쉬면서 작은 빛을 모아 십자가를 완성하는 잔잔한 경험이다.

확정 방향:

- 화면에는 여러 별이 떠다닌다.
- 한 번에 하나의 목표 별만 밝게 반짝인다.
- 사용자는 반짝이는 별 하나를 터치한다.
- 선택된 별은 십자가의 정해진 위치로 이동한다.
- 다음 별이 순차적으로 반짝인다.
- 다른 별은 보이지만 현재 차례가 아니면 활성화하지 않는다.
- 모든 별을 모으면 십자가가 완성된다.
- 드래그 중심 조작보다 이전의 단순 터치 경험을 우선한다.
- 일시정지/처음부터 기능은 유지한다.

2026-09-13 관련 게임 코드 변경 커밋: `df5d0a1f9012a85ad8cb7f98273b33e1eb5b02df`.

화면 안내 문구도 최종적으로 `한 번에 하나씩 나타나는/반짝이는 별을 터치해 주세요`라는 실제 조작과 일치해야 한다.

## 9. 마음카드 → 게임 → 작은 성장 기록 최종 흐름

2026-09-13 확정한 사용자 흐름:

1. 작은 실천 선택
2. 마음카드 요약 표시
3. `마음 카드 저장하기` 탭
4. 마음카드를 기기에 먼저 저장
5. 빛 모으기 게임 시작
6. 모든 별을 모아 게임 실제 완료
7. `작은 성장 기록` 화면 표시

GitHub Issue #4.

중요 규칙:

- 작은 실천을 선택하자마자 게임을 열지 않는다.
- 마음카드를 먼저 보여준다.
- 저장 버튼을 눌렀을 때 카드 저장 성공 후 게임을 시작한다.
- 게임 중 뒤로가기/중단/건너뛰기는 완료로 처리하지 않는다.
- 중단해도 이미 저장된 마음카드는 유지한다.
- 실제 게임 완료 후에만 작은 성장 기록으로 이동한다.
- 공유 버튼은 기존 공유 흐름을 유지하며 게임을 강제하지 않는다.

- 출시 목표 일정은 3월 초 방향으로 관리한다.

장기 확장 방향은 한국 B2C 검증 이후 Faith/B2B, enterprise/senior, API/SDK 플랫폼으로 확장하는 것이다.
