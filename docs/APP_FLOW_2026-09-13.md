# Daily flow

마음선택 → 마음대화 → 오늘의 말씀 → 작은 실천 → 오늘의 마음카드 → 빛 모으기 게임하기 → 돌아가기(마음선택)

- The card's primary action saves the card on-device and replaces the conversation route with the game. This avoids returning to an already completed conversation.
- Save-only stays on the card. Sharing remains optional. Repeated save/share/game actions reuse the same saved card.
- The game can be exited before completion; its return action leads back to the selection screen. Existing menu entry behavior is preserved.
- Existing crisis guards and save-failure handling remain in place.

Validation: full Flutter suite 150 passed / 1 skipped; static analysis passed with four existing example infos; Android debug compilation passed. Integration tests cover normal and failed network turns, repeated saves, game entry, and returning without a conversation route.

Phone installation was attempted through the required Release installer but stopped because the selected device was disconnected. No device data was deleted. No production server changes or CI/push performed.
